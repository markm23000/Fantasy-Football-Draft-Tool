# Fantasy-Football-Draft-Tool
Fantasy Football Draft Value Analyzer

A custom fantasy football draft analysis and automation tool built using Python, Microsoft Excel, and a Chrome extension.

Project Overview

I developed this tool to solve a problem I encountered as a longtime fantasy football player: finding undervalued players while managing the fast-paced demands of a live fantasy draft.

Rather than relying on a single set of rankings, I wanted a way to compare multiple data sources, identify potential values, and track draft selections without constantly switching between applications.

Key Features

Live ESPN Draft Integration: Uses a custom Python bridge and Chrome extension to track ESPN draft selections and update the Excel draft board.

Expert Consensus Rankings: Incorporates FantasyPros ECR to evaluate players against ESPN rankings.

Vegas Player Projections: Uses betting market player projections to add another perspective to player evaluations.

Draft Value Identification: Highlights discrepancies between ranking systems to help uncover potentially undervalued players.

Automated Draft Tracking: Reduces manual updates, allowing users to focus on draft strategy.
